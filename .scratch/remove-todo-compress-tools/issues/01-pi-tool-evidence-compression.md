# 01 — Pi 工具证据压缩边界

**What to build:** 让 Pi 在每次工具执行返回时只接收适合继续推理的证据表示：已知项目范围时不提供项目发现工具；未知范围时项目发现结果只保留项目定位信息；大型检索和代码结果返回可定位摘要，完整内容可由 Pi 按需读取。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Pi 工具 execute 返回给模型的内容已在返回边界完成压缩，而非在外层事件消费后才修改。
- [ ] 已知项目范围时该次 Pi 工具集不包含项目发现工具；未知范围时仍允许 Pi 自主使用它。
- [ ] 项目发现仅返回项目名、路径和分支等最小定位字段，完整内容仍可按需读取。
- [ ] 在安全存储上限内，超出阈值的完整结果可按 offset 读取；超过安全上限时明确返回受控截断提示。
- [ ] 格式无法解析时使用安全占位符回退，不将完整原始结果重新送入模型。
- [ ] 覆盖 Pi execute 返回边界、项目范围判定、结构化摘要、错误状态和按需读取的行为测试。
