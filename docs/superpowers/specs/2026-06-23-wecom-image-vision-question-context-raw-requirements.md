## 初步验收断言

- [ ] 企业微信收到图片或图文混排消息时，先下载图片并调用独立视觉模型识别图片有效内容。
- [ ] 视觉识别 prompt 必须结合当前用户提问文本，重点提取标题、圈选/框选/箭头/高亮内容、图片标注、页面路径、字段名、按钮名、表格列名。
- [ ] 识别结果以结构化文本插入到传给主业务 Agent 的内容中，避免 Planner/检索阶段只能看到原图。
- [ ] 原图仍保留给主模型作为兜底；视觉模型失败时不阻断主流程，并输出失败说明文本。
- [ ] mixed 和 quote 中的图片也走相同识别链路，且上下文标识能区分主消息/引用内容。
- [ ] 通过 mock 测试验证图片识别函数收到当前问题上下文，且解析结果包含识别文本。

## 不适用或暂缓项
