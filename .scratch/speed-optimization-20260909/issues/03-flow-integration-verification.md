# 03 — 请求主流程接入与行为不变验证

**What to build:** 将指标汇总接入现有请求生命周期，覆盖实际阶段和终止路径，并证明观测能力不会改变 Pi、企业微信流式窗口或正常最终回复行为；采集真实样本后再决定性能优化。

**Blocked by:** 01 — request-scoped 指标采集与结构化汇总；02 — 生产脱敏与非生产受控原文调试

**Status:** ready-for-agent

- [ ] 接入敏感预检、媒体处理、MCP 加载、Pi 模型轮次、工具调用、回复队列和最终发送阶段。
- [ ] 正常完成、错误、超时、取消和 TTL 暂停均形成正确的 `terminal_status`。
- [ ] 指标采集不改变 Pi 生命周期、工具执行、TTL 中断和最终回复门槛。
- [ ] 只有真实 `agent_end` 且 `stopReason === "stop"` 的 assistant 文本可作为正常最终回复。
- [ ] 不恢复固定工具预算、旧 Planner、预检索、审核、runtime Todo、direct-evidence 或绕过 Pi 的模型调用。
- [ ] 回归测试验证业务结果、暂停行为和上下文处理不受指标接入影响。
- [ ] 部署或运行样本达到至少 30 个正常请求，并按请求类型、终态、模型和工具输出 n、p50、p95、p99。
- [ ] 仅在真实数据支持时提出后续 MCP、模型、工具或回复链路优化建议。
