# 原始需求归档：analyzed-code-range-index

日期：2026-06-24

## 用户原始需求

> [$my-skill-creator](D:\workplace\skills\my-skills\my-skill-creator\SKILL.md) 精简或者压缩的时候, 需要记录哪些行或代码已经分析过, 如: 方法A:300~500, 避免相同位置反复分析, 浪费时间

## 已采用理解

- 在 `wecom-agent` 当前项目中优化上下文精简和压缩摘要。
- 压缩/精简后的上下文应保留“已分析代码范围索引”，记录已经看过的文件、方法/符号和行号范围。
- 后续模型看到索引后，应优先避开重复读取相同位置，除非需要核实该范围内的具体代码细节。

## 不适用项

- 不涉及数据库、SQL 或生产数据。
- 不改变 MCP 工具本身的缓存策略。
- 不自动提交或推送代码。

## 验收样本

- `compressed_sections` 包含 `{ file_path, symbol, lines: "300-500" }` 时，摘要中出现 `symbol:300~500`。
- 历史文本含 `方法A:300~500` 时，精简摘要中继续保留该范围索引。
- 多个相同文件/方法/行号范围重复出现时，应去重。
