## 初步验收断言

- [ ] `flow_control` 支持上游节点声明后续不需要执行的审核节点。
- [ ] 上游明确声明跳过的审核节点，运行时应程序化标记 done，不再要求模型再次调用 `runtime_todolist_update`。
- [ ] 未声明跳过的节点保持现有审核逻辑，避免默认放宽。
- [ ] SQL 审核仍保留确定性保护：如果最终回答确实输出 SQL 且缺少校验证据，不能被简单跳过。
- [ ] 测试覆盖 JSON 解析、合并、运行时跳过审核项和非法节点过滤。
