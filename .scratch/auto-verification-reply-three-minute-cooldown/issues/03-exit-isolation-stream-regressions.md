# 03 — 特殊退出、会话隔离与流式终态回归

**What to build:** 自动续查接入现有企业微信任务生命周期后，Human Loop、真实模型错误、工具保护和流式过期仍按真实原因立即退出；不同会话的计时和进展互不影响，续查期间流式卡片保持活跃，并在真实终态只结束一次。

**Blocked by:** 01 — 固定三分钟窗口的自动续查闭环; 02 — 新证据门禁与一次纠偏退出.

**Status:** ready-for-agent

- [ ] Human Loop、真实模型错误、工具错误上限和流式过期不等待三分钟，也不转换为证据不足兜底。
- [ ] 私聊用户、不同群聊以及同一群聊的不同发送者使用各自独立的任务时间、证据签名集和纠偏状态。
- [ ] 自动续查期间保持当前活跃任务和流式心跳，中间证据不足判定不结束流式卡片。
- [ ] 正常结论、证据不足兜底、工具无进展、Human Loop 或真实错误进入终态时只完成一次最终回复。
- [ ] 现有最终回复交付回归继续验证正常结论、兜底文案、真实模型错误和 Human Loop 的内容分流。
- [ ] 最小集成测试验证自动续查编排与最终回复交付衔接，不调用真实外部服务。
