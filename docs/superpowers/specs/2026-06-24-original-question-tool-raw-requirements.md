# 原始需求归档：original-question-tool

日期：2026-06-24

## 用户原始需求

> [$my-skill-creator](D:\workplace\skills\my-skills\my-skill-creator\SKILL.md) 为了确保用户问题不丢或者失真, 设置个工具方法,需要的时候, 可以通过方法取到用户最初的问题

## 已采用理解

- 在 `wecom-agent` 当前项目中新增一个 agent 可调用的只读工具方法。
- 工具应返回当前轮用户最初输入的原文，避免后续历史整合、问题改写、prompt 增强或上下文压缩后丢失原问题。
- 为便于排查失真，工具也可以返回当前已整合问题和会话内可见的首个用户问题，但核心字段必须包含当前轮原始用户问题。

## 不适用项

- 不涉及数据库、SQL 或生产数据。
- 不涉及微信连接协议变更。
- 不自动提交或推送代码。

## 验收样本

- 普通提问：工具返回用户直接输入的文本。
- 历史追问整合：工具返回追问原文，同时保留整合后的当前问题，便于模型对照。
- 会话压缩后：工具仍从本轮运行时内存取值，不依赖压缩后的历史文本。
