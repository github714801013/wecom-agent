## 初步验收断言

- [ ] 本地进度/心跳折叠函数不会输出 `[System: Empty message content sanitised to satisfy protocol]`。
- [ ] 企微 `replyStream` 最终出口不会发送该协议占位；清理后为空的非最终帧应跳过，最终帧应使用兜底文案。
- [ ] HTTP 模拟问题“九机物流单详情，什么情况下显示作废按钮”能返回业务答案，且答案不包含 `[System:` 和 `<flow_control>`。
- [ ] 业务答案仍包含作废按钮关键条件：有物流单 ID、状态 1/2/7 或等价条件、`source=1`/手动创建、`作废物流单`、代码证据来源。
