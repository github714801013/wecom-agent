# 02 — 生产脱敏与非生产受控原文调试

**What to build:** 默认只生成脱敏指标；临时隔离非生产环境在独立开关严格等于 `true` 时，允许将受控错误、工具参数和工具返回原文按固定标签追加到普通文本字段，用于排障。

**Blocked by:** 01 — request-scoped 指标采集与结构化汇总

**Status:** ready-for-agent

- [ ] 原文调试默认关闭，只有严格等于 `true` 才开启。
- [ ] 生产部署配置保证关闭原文开关；不新增应用层自动忽略或构造层强制过滤机制。
- [ ] 常规生产指标不记录用户正文、个人信息、会话 key、凭据、完整错误原文或工具数据原文。
- [ ] 非生产原文保留基础脱敏字段，使用固定标签追加到普通文本字段，不新增 `debug` 字段。
- [ ] 错误文本、工具参数和工具返回内容均有固定长度上限。
- [ ] 无法安全序列化时写入固定占位文本，继续记录指标且不影响业务请求。
- [ ] 沿用现有日志系统的权限和保留策略，不新增独立日志文件生命周期。
- [ ] 覆盖关闭、非严格值、开启、截断和序列化失败测试。
