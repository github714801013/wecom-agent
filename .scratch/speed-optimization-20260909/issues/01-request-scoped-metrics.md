# 01 — request-scoped 指标采集与结构化汇总

**What to build:** 为被采样的企业微信请求生成一条可关联的结构化指标汇总，记录关键阶段耗时、速度分类、终止状态和固定错误分类，为后续性能分析提供真实数据。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 生成随机 request ID，并记录 bot、模型、轮次和安全工具标识。
- [ ] 使用单调时钟记录总耗时、敏感预检、媒体处理、MCP 加载、Pi 模型轮次、工具调用、回复队列和最终发送耗时。
- [ ] 阶段耗时为非负整数毫秒；未完成阶段为 `null`。
- [ ] 速度分类遵循：小于 5 分钟为 `normal`，5 分钟至小于 10 分钟为 `slow`，10 分钟及以上为 `very_slow`。
- [ ] 正常请求按 10% 采样；错误、超时、取消、TTL 暂停及慢请求强制记录。
- [ ] 统一记录 `terminal_status` 和固定错误分类。
- [ ] 指标记录失败不影响业务请求。
- [ ] 增加正常、异常、边界和未完成阶段测试，并通过类型检查与测试套件。
