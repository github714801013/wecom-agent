# 02 — 新证据门禁与一次纠偏退出

**What to build:** 自动续查只有在取得新的有效证据工具结果时才能继续。首次无新证据时，Agent 根据剩余证据缺口和已使用调用定向纠偏一次；纠偏仍无进展时如实返回工具无进展原因，避免重复查询或空转到时间上限。

**Blocked by:** 01 — 固定三分钟窗口的自动续查闭环.

**Status:** ready-for-agent

- [ ] 证据调用按规范化工具名和稳定参数组成的任务级签名判重。
- [ ] TodoList 更新不计为证据，任务中已经出现过的相同调用签名不计为新证据。
- [ ] 每个续查轮次至少新增一个此前未见的证据调用结果才视为有进展。
- [ ] 首次无新证据时只允许一次定向纠偏，纠偏上下文包含剩余证据缺口和已使用调用参数。
- [ ] 纠偏后仍无新证据时立即进入明确的工具无进展终态，不等待三分钟，也不发送证据不足兜底。
- [ ] 工具结果数、重复调用数和工具错误数在同一任务的多个续查轮次之间持续累计，现有全局保护阈值和退出语义保持不变。
- [ ] 确定性测试覆盖新唯一证据、TodoList-only、重复签名-only、完全无工具结果和纠偏失败。
